# byte-step

####  Java 기본기를 잊지 않도록 알고리즘과 디자인 패턴을 작은 단위로 학습하고 기록하는 프로젝트입니다. <br><br> 완성된 서비스를 만드는 것보다 직접 코드를 작성하고 테스트하며 꾸준히 개발 감각을 유지하는 것을 목표로 합니다.


## 학습 목표

- 하루에 하나씩 작은 문제나 기능 구현하기
- 알고리즘을 통해 Java 자료구조와 문법 복습하기
- JUnit을 활용해 작성한 코드 검증하기
- 디자인 패턴을 간단한 예제로 직접 구현하기
- 작은 단위로 커밋하며 학습 과정 기록하기

## 학습 범위

- 배열, 컬렉션 등 Java 기본 문법과 자료구조
- 간단한 알고리즘 문제 풀이
- JUnit을 활용한 테스트 작성
- Singleton, MVC 등 디자인 패턴 구현
- Java Swing을 활용한 간단한 GUI 제작
- 예외 처리와 코드 구조 개선

## 학습 방향

먼저 스스로 풀이한 뒤, 해결하지 못한 부분은 다른 풀이를 참고합니다.
문제 푸는 것에 끝내지 않고 헷갈렸던 문법이나 다시 볼 내용도 함께 기록합니다.
처음부터 완벽한 풀이를 만들기보다는 꾸준히 문제를 풀고 개선하는 것을 목표로 하고있습니다.
