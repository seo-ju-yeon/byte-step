# byte-step

Java로 알고리즘 문제를 풀며 기본기를 쌓기 위한 프로젝트입니다.

## 목표

- 꾸준히 알고리즘 문제 풀기
- 문제 해결 과정을 기록하고 복습하기
- Java 기본기와 구현 능력 향상하기
- 시간 및 공간 복잡도를 고려하는 습관 기르기

## 학습 방향

가능하면 먼저 스스로 풀이한 뒤, 해결하지 못한 부분은 다른 풀이를 참고합니다.  
문제를 푸는 것에서 끝내지 않고 헷갈렸던 문법이나 다시 볼 내용도 함께 기록합니다.

처음부터 완벽한 풀이를 만들기보다는 꾸준히 문제를 풀고 개선하는 것을 목표로 합니다.
